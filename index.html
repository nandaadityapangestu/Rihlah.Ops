Hubungkan Supabase

  1. Buka proyek Supabase Anda, lalu Project Settings › API.
  2. Salin Project URL dan kunci anon / publishable (jangan pakai service_role).
  3. Tempel di bagian paling atas index.html:
    var SUPABASE_URL = 'https://xxxx.supabase.co';
var SUPABASE_KEY = 'eyJ...';
  4. Jalankan schema.sql di SQL Editor, lalu muat ulang halaman ini.
